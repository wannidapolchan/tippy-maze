**Tilt the world. Roll the ball. Don't fall in.**
 
A 3D tilt-maze game made in Unity

## 🎮 About the Game
 
Tippy Maze is a 3D tilt-maze game. The player never controls the ball directly. Instead, they tilt the whole board with the joystick or keyboard, and the ball rolls using gravity and physics.
 
The goal is to guide the ball through each maze to the exit without falling into holes or touching moving obstacles. The player can jump to hop over holes and obstacles, but the walls are too tall to jump over.
